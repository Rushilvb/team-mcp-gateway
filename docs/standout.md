# Beyond the brief

Things built in addition to the required features, where they live, and how each is proven.

| Extra | Where | Proof |
|---|---|---|
| **Upstream credentials encrypted at rest** (Fernet; key in a Secret, not the DB), write-only in the API | `gateway/security.py`, `api/servers.py` | tests: credentials never in responses |
| **Client tokens never forwarded upstream** | `gateway/upstreams.py` | fake upstreams record headers in tests |
| **SSRF guard** (scheme, userinfo, cluster-name allowlist, every resolved IP, re-checked on reconnect) + egress NetworkPolicy backstop | `gateway/ssrf.py`, `gateway-networkpolicy.yaml` | 17 parametrised SSRF tests |
| **NetworkPolicies everywhere**, default-deny backstops in both namespaces, fx-mcp with zero egress | `charts/*/templates/*networkpolic*` | `make netpol-check` (21 live checks) |
| **Pod Security Admission**: `restricted` enforced on platform, `baseline` + `restricted` warnings on store | `make namespaces` | `make security-check` (API-server dry run) |
| **Non-root everywhere** except one CHOWN-only init container; seccomp, no SA tokens, read-only root FS for our services | all workload templates | `make security-check` |
| **Host-header (DNS-rebinding) protection** on every MCP endpoint | `MCP_ALLOWED_HOSTS` | test: unexpected Host → 421 |
| **Works with legacy session-based MCP servers** (era probed once, remembered) | `gateway/upstreams.py` | test with a session-only fake upstream |
| **`tools/list_changed`** pushed to subscribed clients; **immediate** refresh on admin changes | `mcp_server.py`, `api/servers.py` | tests (60s health interval proves immediacy) |
| **Cache-based listing + concurrent health loop**: dead upstreams never block `tools/list` | `gateway/upstreams.py` | tests + `dod-check` kill step |
| **Chat via the gateway's own `/mcp`** with short-lived HMAC chat tokens (channel `chat`) | `gateway/chat/` | 16 chat tests with a scripted LLM |
| **Prompt-injection containment**: untrusted-output system prompt, step/time/size limits | `chat/agent.py` | tests: max steps, truncation |
| **Readable LLM failures**: 429 + `Retry-After`, one automatic wait, daily-quota message | `chat/llm.py`, `api/chat.py` | tests incl. fake 429s |
| **WooCommerce OAuth 1.0a signer verified against WooCommerce's own PHP verifier** (golden vector) | `woo-mcp/woo_mcp/oauth.py` | `test_matches_signature_accepted_by_woocommerce` |
| **REST API key generated by Helm**, inserted with WooCommerce's exact hashing (no RBAC for the Job) | `charts/store/files/api-key.php` | Phase 1 check in WP admin |
| **Server-side sessions**, CSRF Origin check, login rate limit, enumeration-safe errors, last-admin guard | `gateway/api/` | 24 REST API tests + `make api-role-check` |
| **Admin can issue a key for a member**; invite links re-issuable | `api/keys.py`, `api/users.py` | tests |
| **Strict CSP** for the dashboard (no inline scripts), clickjacking protection | `dashboard/nginx.conf` | header check |
| **Alembic migrations tested against models** (`alembic check`) and run by an initContainer | `gateway/migrations`, chart | `test_migrations_match_models` |
| **Content-hash image tags**: only changed services roll; immutable tags make `helm rollback` exact | `Makefile` | every deploy |
| **`make dod-check`**: the whole Definition of Done as a live checklist (incl. self-healing) | `scripts/dod_check.py` | 24 checks |
| **`make reset-demo`**: clean demo data in one command (local only, keeps the LLM key) | `scripts/reset-demo.sh` | run in Phase 7 |
| **Tests run against real Postgres** in throwaway containers; no mocks for SQL | `Makefile test` | 95 gateway + 48 MCP-server tests |
| **Same charts local ↔ VPS**, prod deploy guarded (`KCTX` required, refuses the local cluster), `--atomic` | `Makefile`, `values-prod.yaml` | server-side dry run of prod values |

Security inventory with deliberate exceptions: [hardening.md](hardening.md). Threats: [threat-model.md](threat-model.md).
